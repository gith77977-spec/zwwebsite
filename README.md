# ZONEWEAR - Modern Fashion Brand Website

## Overview
ZONEWEAR is a professional, modern e-commerce website for a clothing brand. Built with HTML5, CSS3, and Vanilla JavaScript, it features a responsive design that works seamlessly on desktop, tablet, and mobile devices.

## 📁 Project Structure

```
zonewear/
├── index.html          # Homepage with hero section and featured products
├── products.html       # Product catalog with filtering capabilities
├── about.html          # About us page with team and company info
├── contact.html        # Contact form and customer support information
├── style.css           # Main stylesheet with responsive design
├── script.js           # JavaScript functionality and interactions
└── README.md           # This file
```

## ✨ Features

### 1. **Responsive Design**
   - Fully responsive layout that adapts to all screen sizes
   - Mobile-first approach
   - Hamburger menu for mobile navigation

### 2. **Shopping Cart**
   - Add/remove products from cart
   - Local storage integration to persist cart data
   - Real-time cart count updates

### 3. **Product Management**
   - Product filtering by category (Men, Women, Accessories)
   - Attractive product cards with pricing
   - Gradient backgrounds for visual appeal

### 4. **Pages**
   - **Home**: Hero section, featured collection, why choose us
   - **Shop**: Full product catalog with filtering options
   - **About**: Company story, team members, statistics
   - **Contact**: Contact form, customer support info, FAQs

### 5. **Modern UI/UX**
   - Gradient color schemes (Purple, Pink, Blue)
   - Smooth animations and transitions
   - Hover effects on interactive elements
   - Clean typography and spacing

### 6. **Functionality**
   - Form validation (Contact form)
   - Newsletter subscription
   - Mobile navigation toggle
   - Local storage for cart persistence
   - Notification system

## 🚀 Getting Started

1. **Open in Browser**: Simply open any HTML file in your web browser
   ```
   - Open index.html to view the homepage
   - Or open products.html to view the shop
   ```

2. **No Installation Required**: This is a static website with no backend dependencies

3. **Local Development**: 
   - Use any code editor (VS Code recommended)
   - Use Live Server extension for real-time preview

## 📱 Responsive Breakpoints

- **Desktop**: 1200px and above
- **Tablet**: 768px to 1199px
- **Mobile**: Below 768px
- **Small Mobile**: Below 480px

## 🛒 Shopping Cart Features

- Click "Add to Cart" button on any product
- View cart by clicking the cart icon
- Cart data persists using browser's localStorage
- Simple checkout notification

## 📝 Contact Form

- Name, Email, Phone, Subject, Message fields
- Form validation
- Success/Error notifications
- Data logged to console for backend integration

## 🔧 Customization

### Change Brand Name
- Replace "ZONEWEAR" throughout all HTML files

### Update Products
- Modify product information in products.html and index.html
- Change prices, descriptions, and images

### Update Contact Info
- Edit contact.html with your actual contact details
- Update email addresses, phone numbers, address

### Modify Colors
- Update CSS custom properties in style.css (:root section)
- All gradient colors can be customized
