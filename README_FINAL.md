# 🎉 ZONEWEAR - موقع إلكتروني متكامل جاهز للإنتاج

## 📍 ملخص المشروع

**ZONEWEAR** هو موقع إلكتروني احترافي لبيع الملابس والإكسسوارات، مع لوحة إدمين متقدمة لإدارة المنتجات والطلبات.

### ✅ المميزات الرئيسية:

- 🛒 متجر إلكتروني متكامل
- 👤 لوحة إدمين آمنة
- 📊 إدارة المنتجات والطلبات
- 💾 نظام نسخ احتياطية
- 🔐 أمان عالي (bcryptjs + JWT)
- 📱 متوافق مع جميع الأجهزة
- 🌍 دعم عربي/إنجليزي
- 🚀 جاهز للنشر على الإنترنت

## 🚀 كيفية البدء

### الخيار 1: على جهازك الشخصي (للتطوير)

```bash
# 1. فتح Terminal
cd zwwebsite

# 2. تشغيل الخادم (Terminal 1)
cd backend
npm install
npm start
# سترى: ZONEWEAR Backend Server Running on Port 3000

# 3. تشغيل الموقع (Terminal 2)
python -m http.server 8000

# 4. افتح المتصفح
# الرئيسية: http://localhost:8000
# الدخول: http://localhost:8000/admin-login.html
```


## ❓ الأسئلة الشائعة

### س: هل يمكن تغيير التصميم؟
**ج:** نعم! جميع الملفات قابلة للتعديل. عدّل `style.css` و `script.js`.

### س: هل يمكن إضافة طرق دفع؟
**ج:** نعم! يمكن ربط بوابات دفع مثل Stripe أو Apple Pay.

### س: هل البيانات آمنة؟
**ج:** نعم! مشفرة بـ bcryptjs و JWT مع HTTPS (على الإنترنت).

### س: كم يمكن لقاعدة البيانات أن تتحمل؟
**ج:** SQLite يدعم ملايين السجلات. يمكن الترقية لـ PostgreSQL لاحقاً.

### س: ماذا لو نسيت كلمة المرور؟
**ج:** اتصل بالدعم الفني. يمكن استعادة الوصول من قاعدة البيانات.
